# Console documentation sources

The Console documentation is newly written for Sovereign Next. Its topic map
follows the Cloud Onboarding section of the [Genestack MkDocs configuration](https://github.com/rackerlabs/genestack/blob/main/mkdocs.yml).
The detailed flavor and image guides were informed by the corresponding
[Genestack documentation sources](https://github.com/rackerlabs/genestack/tree/main/docs)
and the upstream [OpenStackClient command reference](https://docs.openstack.org/python-openstackclient/latest/cli/command-objects.html).

Genestack is distributed under the [Apache License 2.0](https://github.com/rackerlabs/genestack/blob/main/LICENSE).
The Console articles use new prose and generic examples; provider-specific
sizes, endpoints, and image files must come from the connected cloud.
